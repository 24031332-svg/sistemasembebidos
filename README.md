## 📚 1. Introducción

Este repositorio contiene las prácticas y proyectos desarrollados durante la asignatura de **Sistemas Embebidos**, correspondiente a la carrera de Ingeniería en Mecatrónica.

Durante el curso se desarrollarán aplicaciones utilizando microcontroladores ESP32, sensores, actuadores y diferentes herramientas de programación, integrando hardware y software para la adquisición de datos, procesamiento de señales y sistemas de control.

El repositorio tiene como finalidad documentar el desarrollo de las actividades realizadas, almacenando códigos fuente, diagramas electrónicos, evidencias visuales y reportes técnicos.

---

## 🎯 2. Objetivos

El desarrollo de la asignatura busca que el estudiante sea capaz de:

1. Comprender los fundamentos de los sistemas embebidos.
2. Programar microcontroladores ESP32.
3. Interactuar con sensores y actuadores.
4. Implementar sistemas de adquisición de datos.
5. Desarrollar aplicaciones de control y automatización.
6. Utilizar herramientas de simulación.
7. Integrar hardware y software.
8. Documentar los resultados de cada práctica.
9. Utilizar Git y GitHub para el control de versiones.

## 🔌 6. Hardware utilizado

Dependiendo de los requerimientos de cada práctica, se podrán utilizar diferentes componentes electrónicos:

| Componente | Aplicación |
|---|---|

| LM35 | Medición de temperatura |
| Potenciómetros | Ajuste de variables analógicas |

## 💻 7. Programación y desarrollo

La programación de los microcontroladores se realizará principalmente mediante **C/C++**, utilizando Arduino Framework y PlatformIO.

También se utilizará Python para desarrollar interfaces gráficas, monitorear variables, visualizar datos y facilitar la interacción entre el usuario y los sistemas embebidos.

---

## 🧪 8. Simulación e implementación

Cuando las características de cada práctica lo permitan, se utilizarán herramientas como Wokwi para realizar simulaciones previas a la implementación física.

Este proceso permitirá verificar conexiones, funcionamiento del código y comportamiento lógico del sistema.

